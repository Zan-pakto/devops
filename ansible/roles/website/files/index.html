The 4 Pillars of the DevOps Pipeline

Every phase is automated, verified, and integrated according to syllabus specifications.

🏗️
Step 01

Terraform

Infrastructure as Code

Provisions complete AWS isolated VPC (10.0.0.0/16), public subnet (10.0.1.0/24), Internet Gateway, strict Security Groups, and dual Ubuntu EC2 instances.

  • Deterministic resource declarations
  • Least-privilege security group rules
  • Auto-generated output variables & SSH keypairs
✓ Provisioned
🎭
Step 02

Puppet

Configuration Management

Enforces desired system state on the target node. Manages Apache2 web server installation, service persistence, directory structures, and system configurations.

  • Master-Agent PKI certificate exchange
  • Declarative manifest (site.pp) enforcement
  • Self-healing drift correction
✓ State Enforced
🚀
Step 03

Ansible

Application Orchestration

Deploys this responsive HTML/CSS/JS application payload to /var/www/html/, sets Linux ownership/permissions (www-data), and verifies HTTP 200 health.

  • Agentless, idempotent SSH execution
  • YAML role & playbook-driven workflows
  • Automated post-deploy smoke testing
✓ Deployed
📡
Step 04

Nagios Core

Continuous Monitoring

Continuously monitors target host availability and HTTP service health. Alerts on latency spikes, downtime, packet loss, or service interruptions.

  • ICMP host-alive ping checks (RTT & loss)
  • Active HTTP 200 response verification
  • Web-based NOC dashboard at /nagios
✓ Monitored
